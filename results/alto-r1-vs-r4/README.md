# ALTO/VTRN 검증 경로의 R1 및 R1+R4 항법 비교

같은 4.57km 비행에서 R4는 연속 항법 시간을 90.05초 늘렸다. 평가한 89걸음 모두 두 방식의 추정 위치가 일치했다.

| 평가 | R1 시간 | R1+R4 시간 | R4 복구 성공/시도 | R1 / R1+R4 방향 매칭 시도 | 최종 위치 오차 (두 방식) |
|---|---:|---:|---:|---:|---:|
| 연속 89걸음 | 38.47초 | 128.52초 | 0/20 | 157 / 594 | 5.50m |
| 약 800m씩 5구간, 80걸음 | 34.38초 | 124.52초 | 0/20 | 148 / 585 | 11.72m |

짧은 구간의 최종 오차는 다섯 끝점 오차의 중앙값이다. 두 프로토콜은 같은 Round 2 Val 비행의 90프레임을 사용한다. 공통 조건은 USGS NAIP 고정 지도, 4방향 LoMa-B, 걸음 내 지도 특징 재사용, GPS 변위에 잡음을 더한 모의 오도메트리다. 실행 ID는 `20261121T085555Z`이며 조건별 1회 측정했다.

중심 블록에서 R1이 실패하면 R4는 십자 이웃을 탐색하고 연속 다섯 번째 실패부터 대각선을 포함한다. 실제로 두 프로토콜 각각 8걸음에서 넓은 탐색을 수행했다. 이 로그는 후보별 탈락 사유를 기록하지 않는다. 다른 경로에서의 복구 효과는 별도 검증이 필요하다.
