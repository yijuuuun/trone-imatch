# iMatch R1 4방향 구조적 가지치기 실험

속도 우선 기준에서는 원본 R1이 가장 빨랐다. 동일 Kaggle 세션에서 UAV-VisLoc seq_eval 92구간을 조건별로 한 번씩 재생했다. 1,112프레임 중 구간 시작점을 제외한 1,020걸음에서 위치 오차와 탐색 방향 수를 집계했다.

| 모델 | 파라미터 (M) | 고정 영상 쌍 중앙값 (ms) | 전체 재생 (초) | 평균 탐색 방향 | 10m / 20m / 32m 이내 (%) | 최종 오차 중앙값 (m) | 최종 40m 이내 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 원본 R1 | 341.5 | 283.5 | 994.8 | 2.59 | 17.9 / 48.7 / 75.4 | 21.2 | 68/92 |
| 25% 가지치기 | 291.2 | 309.0 | 1148.9 | 3.13 | 21.0 / 50.0 / 73.8 | 20.0 | 71/92 |
| 50% 가지치기 | 240.8 | 301.6 | 1085.0 | 3.05 | 22.3 / 51.7 / 74.4 | 22.0 | 67/92 |

사전학습 LoMa-B의 DINOv2 MLP 24개에서 은닉 채널 폭을 4096에서 3072 또는 2048로 줄였다. 추가 학습 없이 세 모델 모두 0°, 90°, 180°, 270° 순으로 탐색하고 inlier 15개에서 조기 종료했다. VIO seed는 2026이다.

25%, 50% 가지치기로 모델 파라미터가 각각 14.7%, 29.5% 감소했다. 고정 영상 한 쌍의 매칭 시간이 늘고 항법 중 탐색 방향 수도 증가했다. 전체 재생 시간은 각각 15.5%, 9.1% 늘었다. 25% 모델은 최종 40m 이내 구간이 3개 늘었다. 각 조건을 한 번씩 측정했으므로 실행 간 변동 폭은 확인하지 못했다.
