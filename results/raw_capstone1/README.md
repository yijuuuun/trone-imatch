# 원본 기록 (capstone1 저장소에서 돌린 그대로)

- `out_imatch/`: capstone1 `diag/out/imatch/`의 원본 출력. Kaggle 커널 로그(`*.log`), 실행 단위별 CSV(`kaggle_smoke/`, `stage2_raw/`), 당시 비교표(`compare_*.csv`).
- `scripts/`: 당시 쓴 원래 스크립트(`imatch_run.py` 등). 이 저장소의 `imatch/`, `scripts/`는 이것을 나눠 정리한 것이며 같은 결과를 내는 것을 확인했다(2026-10-16).

정리된 결과는 상위 `results/`의 CSV를 쓰면 된다.
