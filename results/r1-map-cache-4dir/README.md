# iMatch R1 지도 특징 재사용 결과

UAV-VisLoc seq_eval 92구간에서 같은 걸음의 회전 탐색 동안 지도 특징을 재사용했다. 원본과 같은 4방향(0°, 90°, 180°, 270°), inlier 15개 조기 종료, VIO seed 2026을 적용했다.

| 지표 | 원본 R1 | 지도 특징 재사용 |
|---|---:|---:|
| 전체 항법 시간 | 951.9초 | 660.1초 |
| 프레임당 시간 | 856ms | 594ms |
| 지도 특징 추출 | 2,883회 | 1,112회 |
| 최종 오차 중앙값 | 21.2m | 21.2m |
| 최종 오차 40m 이내 | 68/92 | 68/92 |

같은 Kaggle 세션에서 조건별 한 번씩 측정했다. 재생 시간이 291.8초(30.7%) 줄었다. 1,112개 프레임에서 소요 시간을 제외한 모든 걸음별 기록이 일치했다. 시작점을 제외한 평가 걸음은 1,020개다.
