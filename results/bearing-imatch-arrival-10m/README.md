# 10m 목적지 도착 실험

800m 경로 4개를 이동 오차 시드 2개로 주행한 2D 폐루프 시뮬레이션이다. 기체는 추정 위치가 목표 반경 10m 안에 들면 정지하며, 그때 실제 위치도 10m 이내여야 성공이다. 2017년 지도를 항법에, 같은 지역의 2023년 지도를 모의 카메라 영상 생성에 사용했다.

| 평가 항목 | Bearing-UAV | iMatch R1 | iMatch R1+R4 |
|---|---:|---:|---:|
| 목적지 도착 | 0/8 | 8/8 | 8/8 |
| 종료 시 실제 목표 거리 중앙값 | 731.25m | 3.06m | 3.06m |
| 종료 시 실제 목표 거리 최댓값 | 808.91m | 4.41m | 4.41m |
| 이동 한도 64회 소진 / 지도 유효 범위 이탈 | 4 / 4 | 0 / 0 | 0 / 0 |
| 실제 총 이동 거리 | 11.94km | 6.39km | 6.39km |
| 8회 총 계산 시간 | 41.78초 | 83.83초 | 85.47초 |

Bearing-UAV는 공식 cross_view 가중치로 위치를 예측하고 직전 이동 명령으로 다음 블록을 고른다. iMatch는 영상 간 이동을 추정하고 지도 매칭으로 보정한다. R1+R4는 중심 블록 매칭 실패 시 이웃 블록을 재탐색한다.

두 iMatch 방식 모두 초기점을 제외한 256걸음 전부 중심 블록의 첫 방향에서 성공했다. R4 호출은 0회였고 실제·추정 궤적이 일치했다. Bearing의 계산 시간에는 실패로 종료한 주행도 포함된다. 이 비교는 한 지역에서 각 모델과 이동 예측을 결합한 시스템을 측정했으며 실패 원인을 모델 단독으로 분리하지 않았다.
