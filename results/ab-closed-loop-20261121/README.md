# A→B 폐루프 도착 실험

2017년 정사영상으로 위치를 추정하고 같은 지역의 2023년 정사영상으로 모의 카메라 화면을 생성했다. 각 방식은 800m 경로 4개를 이동 잡음 시드 2개로 주행했다. 추정 위치를 기준으로 정지한 순간 실제 위치가 목표 반경 20m 안이면 도착으로 판정했다.

| 지표 | R1 | R1+R4 |
|---|---:|---:|
| 도착 성공 | 8/8 | 8/8 |
| 잘못된 정지 / 시간 초과 / 지도 이탈 | 0 / 0 / 0 | 0 / 0 / 0 |
| 도착 시 실제 목표 거리 중앙값 | 3.06m | 3.06m |
| 실제 총 이동 거리 | 6,393.64m | 6,393.64m |
| 총 계산 시간 | 83.29초 | 85.41초 |

초기 위치를 제외한 256걸음 모두 중심 블록에서 첫 방향으로 매칭됐다. 따라서 R4를 켠 조건에서도 이웃 탐색은 0회였다. 두 방식은 초기점을 포함한 264행에서 실제·추정 좌표 및 탐색 횟수가 모두 일치했다. 8회 도착 시 실제 목표 거리는 0.80~4.41m였다.

동일한 정사영상 범위와 두 시드에서 얻은 2D 시뮬레이션 결과다. R4가 발동하지 않았으므로 이번 실행만으로 복구 효과를 평가하거나 2.12초 차이를 복구 비용으로 해석할 수 없다.
