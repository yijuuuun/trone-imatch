# 헤딩 4방향 vs 8방향: 학습 도시 확인 (새로 돌리지 않음)

#37(강지민)은 4방향 + 멈추기 15를 UAV-VisLoc 평가용(`single_eval`)으로 골랐다. 설정은 학습 데이터에서 골라야 하므로, 학습 도시에 이미 있던 16방향 기록(`experiments/2026-11-06_c3_train_data/loma_16dir_{tk,tp}_angles.csv`, 도시마다 500장)에서 4방향·8방향을 다시 계산했다. 16방향은 8방향과 4방향을 모두 포함한다.

```bash
PYTHONPATH=. python scripts/reduce_dirs.py experiments/2026-11-06_c3_train_data/loma_16dir_tk.csv
PYTHONPATH=. python scripts/reduce_dirs.py experiments/2026-11-06_c3_train_data/loma_16dir_tp.csv
```

(`scripts/reduce_dirs.py`는 #38)

- 4방향 + 멈추기 vs 8방향 + 멈추기 (McNemar, 10 m): 도쿄 5 vs 8 (p = 0.58), 타이베이 0 vs 2 (p = 0.50). 차이 없음.
- 학습 도시 1 km(#39)도 4방향과 8방향 성공 궤적이 같다.
- **결론: 4방향 + 멈추기 15 선택은 학습 도시만으로도 같은 결론.** #37의 UAV-VisLoc 표는 평가 데이터에서의 확인 결과로 쓴다.
