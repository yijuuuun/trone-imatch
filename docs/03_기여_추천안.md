# 우리만의 기여 추천안 (2026-10-16, 검토 중)

현재 파이프라인의 부품(LoMa, MAGSAC++, 호모그래피)은 모두 기존 것이다. 아래 세 가지 중 하나 이상을 우리가 만든 것으로 내세운다.

## 근거로 쓸 우리 데이터 (3D, 1,000샘플)
- Singapore 76.1% (SF 96.6%). 실패 13%, 32 m 초과 8%. inlier 중앙값 57개 (SF 294개)
- LoMa와 RoMa v2 중 하나라도 맞힌 비율 82%. 그러나 단순 inlier 비교 조합은 76%로 효과 없음
- 회전 탐색 없이 1방향만 써도 Singapore 72.9% (8방향 75.4%), 사진 1장당 0.29 s

## 추천 1 (먼저): 실패를 아는 후보 선택기 — C3
- 무엇: 한 문제에 후보 여러 개(8방향 × LoMa/RoMa v2 × 축척)를 만들고, 학습한 작은 모델이 "어느 후보가 맞는지, 아예 다 틀렸는지"를 판정
- 입력 특징: inlier 수·비율, 재투영 오차, 호모그래피의 축척·찌그러짐, 대응점 공간 분포, 1등·2등 후보의 차이
- 학습 데이터: Bearing-UAV 학습 도시에서 자동 생성 (정답 위치를 알기 때문)
- 새로운 점: 매처 출력을 "그대로 믿는" 기존 파이프라인과 달리, 이 과제 전용 신뢰도 판정기를 둔다
- 목표: Singapore 76% → 82%(상한)에 근접. 틀린 답 대신 "모름"을 내서 32 m 초과 8%를 줄임
- 비용: CPU로 학습 가능. 며칠

## 추천 2 (핵심 기여): 드론-지도 전용으로 매처 미세조정 — C2(b)
- 무엇: LoMa의 매칭 부분(약 37 M 파라미터)을 Bearing-UAV 학습 도시로 추가 학습. DINOv2는 고정
- 정답 대응점: 데이터셋의 정답 위치·heading으로 자동 생성
- 1방향(0.29 s)으로도 8방향 이상의 정확도를 내는 것을 목표로 함
- 새로운 점: 범용 매처를 원 논문의 데이터로 "드론→지도" 영역에 맞춤. 시험 도시는 학습에서 완전히 뺌
- 목표: 1방향으로 Singapore 72.9% → 76% 이상
- 비용: Kaggle T4로 가능하나 1~2주

## 추천 3 (확장): 연속 프레임을 쓰는 항법 — C4
- 무엇: 한 장이 실패해도 이전 프레임 위치와 이동량으로 후보 블록과 방향을 좁히고 복구
- 목표: 3D 1 km 항법 성공률
- 비용: 추천 1이 있어야 효과가 큼

## 추천 순서
추천 1 → 추천 2 → 추천 3. 추천 1이 빠르고 근거(82%)가 이미 있다. 추천 2가 가장 독창적인 "우리가 만든 모델"이다.
