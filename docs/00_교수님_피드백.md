# 교수님 피드백 (2026-10-15)과 이후 방향

## 1. 피드백 원문

> 나침반 없이 영상만 써도 괜찮다. 실시간성은 충분하다.
> 아이디어가 너무 나이브하다. 여러번 돌려가며 계산을 한다…. 이게 베스트라고하면 걍 하면됨. 연산량이 많아지는게 부담스럽진 않음. 이미지 매칭하는 연구들이 따로있음.. 요 연구안에서만 찾을라고하지말고, 그 서브문제를 푸는 다른 연구들을 가져와라. 문제랑 유사문제를 푸는 다른연구가 있다하면 그걸 찾아서, 적용해라. 문제를 분할해서, 서브프라블럼을 만들고, 그 서브프라블럼만 푸는 다른 연구들을 찾아서 거기서 제시하는 방법들을 적용하자. 그게 훨씬 더 맞지 않나?
>
> 결국엔 피처매칭이 안되서 그런거다. 이미지 매칭이라는 분야로 넘어가야한다. 이 피처랑 이미지랑 얼마나 매칭이되나 이걸 뽑아야한다 많이.. 이 뽑은걸 기반으로 상대관계를 추론해야되는건데 이게 안되는거니까 어그러지는거임. 이미지매칭쪽으로 리서치를 좀 더 해봐라.
>
> 이미지매칭 오픈소스를 찾아서… 테스트를 해봐라.
> 문제정의는 잘 했는데, 직관적인 방법말고 솔루션도 기존에 연구들을 찾아보아서 도입할만한 기술을 적용해봐라.
>
> 저조도보다 중요한게 새로운 환경에서 잘되는게 중요함.

## 2. 요약

| 피드백 | 우리가 바꿀 점 |
| --- | --- |
| 솔루션이 직관적이다 | VGG 상관 + argmax(B2, CorrMatchNet)를 주 방법에서 내리고, 검증된 매칭 파이프라인으로 교체 |
| 실패 원인은 피처 매칭. 대응점을 많이 뽑고 그걸로 상대 관계를 추론해야 한다 | 대응점 수, inlier 비율, 오매칭 비율을 지표로 추가 |
| 서브문제로 나누고 각각 기존 연구를 가져와라 | 회전 · 매칭 · 검증 · 기하 추론 · 블록 선택으로 분할 |
| 오픈소스를 테스트해라 | vismatch로 SIFT-LightGlue, LoMa, RoMa v2 등 비교 |
| 나침반 없이 OK, 연산량 OK, 반복 OK | vision-only가 주 조건. 각도 탐색·반복 정밀화 허용. R5(가벼움) 제외 근거 철회 |
| 저조도보다 새 환경 일반화가 중요 | 미학습 도시 3D와 외부 데이터셋 중심으로 평가, 저조도는 마지막 |

## 3. 서브문제와 가져올 연구

| 서브문제 | 현재 | 가져올 방법 | 근거 연구 |
| --- | --- | --- | --- |
| ① 회전 맞추기 | 16각도 상관 최대 | 각도 탐색을 inlier 수로 판정 / yaw 추정 모듈 | [AeroMap3D](https://arxiv.org/html/2607.14009v1) (2026) |
| ② 피처 추출 · ③ 매칭 | 고정 VGG conv4_3 상관 | RoMa v2, LoMa, GIM, SIFT/ALIKED-LightGlue | [RoMa v2](https://arxiv.org/abs/2511.15706), [LoMa](https://arxiv.org/html/2604.04931v1), [GIM](https://arxiv.org/pdf/2402.11095) |
| ④ 매칭 검증 | 없음 | 상호 최근접 + MAGSAC++, inlier 수 = 신뢰도 | 공통 |
| ⑤ 위치·heading | argmax | 호모그래피, 반복 정밀화 | [EarthMatch](https://arxiv.org/html/2405.05422v2) (CVPRW 2024) |
| ⑥ 블록 선택 | 예측 위치 기준 | Top-N 후보 매칭 후 inlier로 재선택 | [AnyVisLoc](https://arxiv.org/html/2503.10692v2) (2025) |

조사 당시 수치(각 논문 자체 보고):
- AeroMap3D: 고정된 RoMa v2의 등록 성공률이 62.4%에서, 회전·축척 보정을 넣으면 99.2%. SIFT+LightGlue는 35.1%.
- AnyVisLoc: 5 m 이내 비율이 RoMa 73.9%, GIM-DKM 68.5%.
- EarthMatch: RoMa 93.0%, Steerers 90.6%, SIFT-LightGlue 89.3%. 이전 세대 RoMa는 256 px 이하에서 실패.
- 회귀 방식은 오차가 큼: Bearing-UAV(원 논문)는 우리 측정 기준 미학습 도시 20.6 / 21.6 m, SatFix는 위치 중앙값 45.7 m.
