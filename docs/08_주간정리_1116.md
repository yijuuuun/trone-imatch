## 1. 확정된 v1

**LoMa 4방향 + 멈추기(inlier ≥ 15) + R1 + R4**

- R1: inlier < 15면 "모름" → 추측 항법 (예방)
- R4: "모름"이면 그 걸음에서 바로 십자 5블록 재매칭, 5걸음 연속이면 3×3 9블록(inlier ≥ 20) (복구)
- 근거: 4방향은 개발용 데이터 두 곳에서 8방향과 정확도 차이 없음 — 학습 도시([2026-11-16_heading_train](../experiments/2026-11-16_heading_train/README.md)), UAV-VisLoc `single_calib` 513장(4방향 + 멈추기 0.80초 vs 8방향 2.45초, 10 m 15.6% vs 16.8%, p ≥ 0.14, [#40](../experiments/2026-11-16_heading_dirs_visloc_calib/README.md)). R4는 학습 도시에서 손해 없음 + 교수님 피드백 1 + UAV-VisLoc에서 5구간 더 살림(#36).

## 4. 짚어야 할 것

1. **UAV-VisLoc 한 장에서 우리 숫자가 두 개다. 32 m에서는 원 모델이 높다.**

   | | 10 m | 20 m | 32 m |
   | --- | --- | --- | --- |
   | Bearing-UAV 공개 가중치 (재홍) | 10.4% | 37.6% | 74.5% |
   | LoMa 8방향 + 멈추기, "이전 측정" (재홍 표) | 9.0% | 29.5% | 51.1% |
   | LoMa 8방향 + 멈추기 (지민 #37) | 14.0% | 40.3% | 66.6% |
   | LoMa 4방향 + 멈추기 = v1 (지민 #37) | 14.0% | 40.4% | 66.7% |

   - 같은 1,738장인데 재홍 표의 우리 행과 지민 결과가 다르다. 재홍 표의 우리 행은 "이전 측정"이라 데이터 버전·"모름" 처리 방식이 다를 수 있다 → 재홍 표의 우리 행을 지민 결과(또는 같은 커널 재실행)로 바꾸고, "모름"을 실패로 셌는지 적기.
   - 지민 결과 기준으로 10·20 m는 우리가 높고, 32 m는 원 모델이 높다.
   - 지민 채점(`imatch.metrics.errors`)은 "모름"을 실패가 아니라 블록 중심 답으로 친다. 원 모델도 항상 블록 안의 답을 내므로 이쪽이 같은 조건이다. 보고서에 이 규칙을 적는다.

   - 우리는 "모름"(약 47%)을 실패로 센다. 원 모델은 항상 블록 안의 답을 낸다. 블록이 128 m라 "아무 답"도 32 m 안에 꽤 들어간다(중앙 예측 10 m 7.8%, 32 m는 확인 필요).
   - GPS 라벨 어긋남(10~16 m)이 10 m 기준을 흐린다.
   - → **같은 실행에서** 비교하고, "답한 것만"의 정확도와 거절 비율을 같이 보고. 중앙 예측 기준선을 20·32 m까지.
   - → 항법에서 비교해야 R1·R4의 의미가 드러난다(원 모델은 R0 조건). **원 모델 seq_eval 항법이 가장 급하다.**
2. **원 모델(B1) 파인튜닝이 아직 없다.** 재홍의 파인튜닝은 LoMa 대상. 교수님 피드백 7. 할지 결정 필요.
3. 재홍 표의 iMatch 행은 "이전 측정"이라 시간 조건이 다르다. 확정 v1로 같은 커널에서 다시.
4. 보고서(05) 7장의 R4 설명이 "5걸음 후 3×3"만 적혀 있음 → 바로 하는 십자 재매칭 포함으로 고치기.
