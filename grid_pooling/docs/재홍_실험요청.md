# Grid Pooling 후속 실험 분담 안내

작성: 이준 · 2026-10-09 · 대상: 김재홍 · 기한: **10/15 (수)**

다음 주까지 Grid Pooling을 기반으로 실험을 나눠 진행하기로 해서, 분담 내용과 실행 방법을 정리했습니다. **각자 자기 컴퓨터에서 학습부터 평가까지 독립적으로 진행**하고, 끝나면 결과 표만 공유하는 방식입니다. 컴퓨터 종류(NVIDIA GPU가 있는 PC, Mac, Colab)와 관계없이 같은 명령으로 실행할 수 있습니다.

---

## 1. 배경

CSMG 자리에 **Grid Pooling**(특징 지도를 4×4 칸으로 나눠 칸마다 평균을 내는 방식)을 넣었습니다. 같은 설정으로 다시 학습한 CSMG와 비교했을 때, **미학습 도시 3곳의 1 km 항법 성공률이 23.1%에서 41.3%로 올랐습니다**(NY, Paris, London 160궤적, p=0.0003). 다만 학습 시드 하나로 한 번씩만 학습한 결과라서, 이번 실험으로 결과를 검증하려고 합니다.

## 2. 분담

| | 질문 | 담당 |
| --- | --- | --- |
| **A** | **시드를 바꿔 다시 학습해도 Grid가 CSMG보다 나은가?** | **김재홍** |
| **B** | **Grid를 오래(20 epoch) 학습하면 원래 Bearing(100 epoch)보다도 유의하게 나은가?** | **김재홍** |
| C | 격자 칸 수(1×1, 2×2, 8×8)에 따라 성능이 어떻게 달라지는가? | 이준 |
| D | 어두운 영상을 섞어 학습하면 어두운 조건의 성능이 좋아지는가? | 이준 |

비교 대상이 되는 기존 모델(`grid`, `csmg`, 시드 0)은 `code/models/`에 넣어 두었습니다. 설치하면 자동으로 들어갑니다.

## 3. 공통 규칙

1. **학습 설정은 바꾸지 않습니다.** 코드 기본값(batch 64, AdamW 3e-4, 90K 전체)을 그대로 사용하고, 명령어의 **tag**와 **epoch 수**만 바꿉니다.
2. **비교는 같은 컴퓨터에서 평가한 숫자끼리만 합니다.** 컴퓨터가 다르면 같은 모델도 항법 결과가 조금 달라질 수 있습니다. 그래서 기존 모델도 각자 컴퓨터에서 다시 평가하도록 했습니다.
3. 학습 중에는 **컴퓨터가 잠자기 상태로 들어가지 않게** 해 주세요(노트북은 전원 연결, 덮개 열어 두기).

## 4. 준비 (처음 한 번)

필요한 것: **Python 3.9 이상, PyTorch, torchvision, opencv-python, pandas**, 디스크 여유 공간 **약 15 GB**

1. 공유한 **`code` 폴더**를 내려받아 주세요.
   - `diag/`의 4개 파일은 **주희윤님의 코드**(항법 시뮬레이터, 진단)입니다. 수정하지 않고 그대로 사용합니다.
   - `models/`의 `grid.pth`, `csmg.pth`는 비교 대상인 기존 모델입니다.
2. 터미널을 `code` 폴더에서 열고 설치합니다. 원 저장소 코드, 모델 가중치, 데이터셋(6.3 GB)을 내려받아 풉니다. 20분~1시간 정도 걸리며, 중간에 끊기면 다시 실행하면 이어서 받습니다.
   ```
   python setup_local.py
   ```
   - 설치 위치는 기본적으로 홈 폴더의 `bearing`입니다. 다른 위치에 두려면 `python setup_local.py D:\bearing`처럼 경로를 지정하면 됩니다.
   - 패키지가 없다는 에러가 나면 `pip install torch torchvision opencv-python pandas`를 실행해 주세요.
3. **설치 확인과 속도 측정** (약 5분)
   ```
   python run.py check
   ```
   마지막에 `CHECK_OK`가 나오면 준비가 끝난 것입니다. 출력된 "4 epoch 약 몇 시간"을 참고해 일정을 잡아 주세요.
   - `cuda`(NVIDIA GPU): CSMG 4 epoch에 1시간 안팎
   - `mps`(Mac): 7~8시간이라 하루에 하나씩 밤에 실행하는 것을 권장합니다.
   - `cpu`: 너무 느려서 진행이 어렵습니다. 이 경우에는 알려 주세요.

> **Colab을 사용하는 경우:** `code` 폴더를 Drive에 올리고, 런타임을 T4 GPU로 바꾼 뒤 Drive를 마운트합니다(`from google.colab import drive; drive.mount('/content/drive')`). 이후 아래 명령 앞에 `!`를 붙이고 경로를 지정해 실행하면 됩니다. 예: `!python /content/drive/MyDrive/code/setup_local.py /content/bearing`. 무료 Colab은 하루 GPU 사용 한도가 약 2시간이므로 날짜를 나눠 실행해 주세요.

## 5. 실험 A: 시드 반복 (필수)

**질문:** 시드를 바꿔 다시 학습해도 Grid가 CSMG보다 나은가?

**① 학습** (모든 명령은 `code` 폴더에서 실행)
```
python run.py train csmg_s1 4
python run.py train csmg_s2 4
python run.py train grid_s1 4
python run.py train grid_s2 4
```
- 소요 시간: CSMG는 `check`에서 나온 시간이고, Grid는 그보다 훨씬 빠릅니다(Mac M3 기준 CSMG 약 7시간, Grid 약 3시간).

**② 평가** (시드 0 기존 모델까지 함께 평가)
```
python run.py eval csmg csmg_s1 csmg_s2 grid grid_s1 grid_s2
```
- 공개 가중치(원래 Bearing)도 자동으로 함께 평가됩니다.
- 결과 파일: `bearing/out/eval_more_csmg_csmg_s1_csmg_s2_grid_grid_s1_grid_s2.txt`

**③ 공유할 것:** 위 결과 파일과 아래 표

| 모델 | 시드 0 | 시드 1 | 시드 2 | 평균 |
| --- | --- | --- | --- | --- |
| 공개 가중치 | | — | — | — |
| CSMG 재학습 | | | | |
| Grid | | | | |

- 각 칸에는 결과 파일의 **NY, Paris, London 성공 수를 더해 160으로 나눈 값**을 적어 주세요.
- 같은 시드끼리 Grid 대 CSMG의 McNemar 결과(`vs csmg +a/-b p=...`)도 함께 적어 주세요.

## 6. 실험 B: 긴 학습 (권장, 실험 A 이후)

**질문:** Grid를 20 epoch 학습하면 원래 Bearing(공개 가중치, 100 epoch)보다도 유의하게 나은가? 현재 41.3% 대 32.5%이지만 p=0.087로 아직 유의하지 않습니다.

```
python run.py train grid 20
python run.py eval grid grid_e20
```
- 4 epoch이 아닌 경우 저장 이름에 epoch 수가 자동으로 붙어(`grid_e20.pth`) 기존 모델을 덮어쓰지 않습니다.
- 소요 시간은 Grid 4 epoch의 약 5배입니다. 너무 오래 걸리면 10 epoch(`python run.py train grid 10`, 저장 이름 `grid_e10`)으로 진행해도 됩니다.

**공유할 것:** 결과 파일과 한 줄 요약 (예: "grid_e20 합계 OO% vs 공개 가중치 OO%, +a/-b p=...")

## 8. tag 규칙

| tag | 의미 |
| --- | --- |
| `csmg` | 원래 CSMG를 같은 설정으로 재학습 (대조군) |
| `grid` | 4×4 Grid Pooling (제안 방법) |
| `_sK` | 학습 시드 K (예: `grid_s1`). 없으면 시드 0 |
| `_eN` | N epoch 학습 (4가 아니면 자동으로 붙음, 예: `grid_e20`) |

문의 사항은 언제든 연락 주세요.
