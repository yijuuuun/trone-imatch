# Grid Pooling 실험 분배 (이준 + 재홍, ~10/15)

작성: 2026-10-09
기반: 이준의 Grid Pooling (CSMG 자리에 4×4 격자 풀링). 같은 설정의 CSMG 재학습 대비 미학습 도시 3곳 항법 23.1% → 41.3% (p=0.0003).
코드: 이준 `code/` 폴더 (`train_swap.py`, `eval_more.py` 등). 모든 실험은 이 코드로 돌린다.

## 규칙
1. **학습은 각자, 최종 평가는 이준 Mac에서 한 번에 한다.** 같은 모델도 장치(Mac/Colab)가 다르면 항법 결과가 조금 달라진다. 재홍은 학습한 `.pth`와 `train_*.txt`를 공유 Drive에 올리고, 확인용 평가만 자기 환경에서 돌린다.
2. **설정은 바꾸지 않는다.** 4 epoch, batch 64, AdamW 3e-4, 90K 전체. 바꾸는 건 tag(모델 종류, 시드, 옵션)뿐이다.
3. **나눈 기준:** 무거운 학습(CSMG, 긴 학습)은 빠른 GPU(Colab T4)를 쓸 수 있는 재홍이 맡는다. 이준 Mac은 CSMG 학습에 7시간이 걸리지만 T4는 40분이다. 가벼운 학습(Grid 계열)과 분석 실험은 이준이 맡는다.

## 재홍 (Colab T4)

| # | 우선 | 실험 | tag / 명령 | 질문 | 시간 (T4) |
| --- | --- | --- | --- | --- | --- |
| P1 | 필수 | **CSMG 시드 반복** | `csmg_s1`, `csmg_s2` | 대조군도 시드가 바뀌면 그대로인가? | 각 약 40분 |

### tag 규칙
| tag | 의미 |
| --- | --- |
| `csmg` | 원래 CSMG를 같은 설정으로 재학습 (대조군) |
| `grid` | 4×4 격자 풀링 (제안) |
| `gridN` | N×N 격자 (`grid1`, `grid2`, `grid8`). 출력 1024 유지, 채널 = 1024 / N² |
| `grid_north` | 나침반으로 북쪽 정렬 후 4×4 격자 |
| `_dark` | 학습 UAV 영상의 50%를 L1~L3 중 하나로 어둡게 (예: `grid_dark`) |
| `_sK` | 학습 시드 K (예: `csmg_s1`, `grid_dark_s1`). 없으면 시드 0 = 지금까지의 결과 |
