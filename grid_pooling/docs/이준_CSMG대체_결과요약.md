# CSMG 대체 실험 설계 및 결과 요약 (이준)

## 1. 실험 목적

기존 Bearing-UAV의 **CSMG 모듈을 다른 aggregation 방식으로 바꿨을 때 낯선 도시에서의 항법 성공률이 좋아지는지 확인**한다.

- 목표: **낯선 도시(학습에 없는 도시)에서의 성능 향상**과 경량화
- 기존 CSMG 출력 차원: `[B, 1024]`
- 비교 지표:
    - 1 km 닫힌 루프 항법 성공률 ↑ (주 지표)
    - 위치오차 MLE ↓ (보조 지표)

---

## 2. 문제 확인: CSMG는 무엇을 잃는가 (학습 없음)

같은 VGG16 conv4_3 특징 지도 위에서 aggregation 방식만 바꿔, 블록의 2×2 타일 중 UAV 영상 중심이 있는 타일을 맞힌 비율을 비교했다(우연 25%, 도시별 200샘플). 희윤의 `diag_gluf` 코드를 사용했다.

| 방법 | Tokyo (학습 도시) | NY (낯선 도시) |
| --- | --- | --- |
| CSMG (학습됨) | 85.5% | **59.0%** |
| VGG GAP / GeM (학습 없음) | 56.0% / 52.5% | 52.0% / 55.0% |
| dense 매칭 (요약하지 않음) | 95.5% | **96.0%** |
| Bearing 전체 위치오차 | 5.3 m | 19.6 m |

- 특징 지도를 벡터 하나로 요약하는 방식은 낯선 도시에서 모두 52~62%로 떨어진다. 요약하지 않는 dense는 96%를 유지한다. → **위치 정보는 VGG 특징에 남아 있고, 요약 단계에서 사라진다.**
- CSMG는 학습 도시에서 85.5%지만 낯선 도시에서는 학습 없는 풀링과 비슷하다. → **CSMG가 학습으로 얻은 이득은 학습 도시에만 남는다.**

---

## 3. CSMG 대체 실험 설계

기존 구조:

```
VGG16 (freeze)
→ CSMG
→ RCE
→ Cross-Attention
→ PSG
→ Regression Head
```

대체 구조:

```
VGG16 (freeze)
→ Grid Pooling
→ RCE
→ Cross-Attention
→ PSG
→ Regression Head
```

RCE, Cross-Attention, PSG, Regression Head는 그대로 두고 **aggregator만 교체**했다.

### Grid Pooling (공간 격자 풀링)

```
VGG conv4_3 [B,512,32,32]
→ 1×1 Conv + BN + ReLU (512 → 64)
→ 4×4 Adaptive Average Pooling [B,64,4,4]
→ 칸별 L2 정규화
→ Flatten → L2 정규화 [B,1024]
```

- 특징 지도를 4×4 칸으로 나눠 **칸마다 따로 요약**한다. "무엇이 있는지"와 함께 "어디에 있는지"가 남는다.
- 출력이 `[B,1024]`로 CSMG와 같아서 뒷단을 바꾸지 않는다.
- 학습 가능한 클러스터 중심이 없어서, 학습 도시의 모습을 외울 여지가 적다.
- 파라미터: **0.033 M** (CSMG 1.31 M의 약 1/40)

### 비교 대상

| 모델 | 설명 |
| --- | --- |
| 공개 가중치 | 원 논문 설정 (100 epoch, 증강) |
| **CSMG 재학습 (대조군)** | Grid Pooling과 **같은 설정으로** CSMG를 다시 학습 |
| **Grid Pooling** | 제안 |
| Grid Pooling + 북쪽 정렬 | UAV 영상을 나침반 방향으로 북쪽 정렬한 뒤 Grid Pooling |

CSMG 재학습은 해결책이 아니라 **대조군**이다. "개선이 모듈 교체 덕분인지, 재학습 덕분인지"를 가르기 위해 넣었다.

### 학습 설정 (모든 모델 동일)

- Train: 90K 중 95% (학습 도시 4곳: Tokyo, Taipei, Singapore, SF), Val: 5%
- Epoch: 4, Batch size: 64, AdamW lr 3e-4 (cosine 감소)
- Loss: SmoothL1 (위치 0.8 + 방향 0.2)
- VGG16: Freeze, VGG를 제외한 나머지는 같은 시드로 새로 초기화
- 증강: 없음

### 평가

- **1 km 닫힌 루프 항법** (희윤의 항법 시뮬레이터), 2D 위성 크롭, 나침반 heading
- 낯선 도시: NY 96궤적, Paris 32궤적, London 32궤적 (시드 2026)
- 같은 궤적에서 McNemar 정확검정

## 4. 결과

### 학습 도시 검증 오차 (Val, 4 epoch)

| Model | MLE ↓ |
| --- | --- |
| CSMG 재학습 | **7.68 m** |
| Grid Pooling | 18.55 m |
| Grid Pooling + 북쪽 정렬 | 9.57 m |

### 낯선 도시 1 km 항법 성공률 ↑

| 도시 (궤적) | 공개 가중치 | CSMG 재학습 | **Grid Pooling** | Grid 대 CSMG 재학습 |
| --- | --- | --- | --- | --- |
| NY (96) | 32.3% | 24.0% | **41.7%** | +28/-11, **p=0.0095** |
| Paris (32) | 37.5% | 21.9% | **43.8%** | +10/-3, p=0.092 |
| London (32) | 28.1% | 21.9% | **37.5%** | +8/-3, p=0.23 |
| **합계 (160)** | 32.5% | 23.1% | **41.3%** | +46/-17, **p=0.0003** |

(+a/-b: Grid만 성공한 궤적 a개, CSMG 재학습만 성공한 궤적 b개)

### 기타

- **Grid 대 공개 가중치 (합계):** 41.3% 대 32.5%, +36/-22, p=0.087 (방향은 같지만 유의하지 않음)
- **CSMG 재학습 대 공개 가중치 (합계):** 23.1% 대 32.5%, p=0.03 (재학습하니 오히려 나빠짐)
- **어두운 조건 (NY L2, 32궤적):** 공개 가중치 53.1%, Grid 53.1%, CSMG 재학습 40.6% → 개선 없음
- **Grid + 북쪽 정렬:** 검증 오차는 좋지만 항법에서는 Tokyo 9.4%, NY L2 34.4%로 나쁨. 원인 미확인 (데이터셋과 시뮬레이터의 회전 규약 차이 의심)
- **속도 (Mac M3, 64샘플, 순전파+역전파):** CSMG + 헤드 3.9 s, Grid + 헤드 0.10 s

---

## 5. 분석

- **학습 도시에서는 CSMG가 가장 좋고, 낯선 도시에서는 가장 나쁘다.** 검증 오차는 CSMG 재학습이 Grid의 절반 이하인데(7.7 m 대 18.6 m), 낯선 도시 항법에서는 Grid가 앞선다(41.3% 대 23.1%). CSMG는 학습 도시의 모습을 외우고 낯선 도시로 일반화하지 못한다.
- 따라서 **학습 도시 테스트셋으로 비교하면 CSMG가 가장 좋아 보인다.** 공식 테스트 분할은 테스트 블록이 학습에 포함되어 있어(누수) 이 경향이 더 강해진다. aggregator를 비교할 때는 낯선 도시에서 평가해야 한다.
- **재학습만으로는 해결되지 않는다.** 같은 설정의 CSMG 재학습은 공개 가중치보다도 낮았다. 개선은 aggregator 교체에서 나온다.

---

## 6. 현재 결론

- CSMG의 숨은 문제는 **위치 정보 손실과 학습 도시 과적합**이다 (2절).
- CSMG를 **Grid Pooling으로 바꾸면 낯선 도시 3곳에서 항법 성공률이 23.1% → 41.3%로 오른다** (같은 설정 대비, p=0.0003). 모듈 크기는 1/40이다.
- 공개 가중치(100 epoch) 대비 개선은 아직 유의하지 않다(p=0.087).
- 어두운 조건은 개선되지 않았다. VGG 특징 자체의 한계로 본다.

## 7. 한계 및 다음 단계

- 2D 위성 크롭과 나침반 heading을 가정했다. 3D 시점은 확인하지 않았다.
- 학습 시드는 하나다. 시드 2~3개로 반복해야 한다.
- CSMG 재학습은 Mac(MPS), Grid는 Colab(T4)에서 학습했다(설정은 같고 정밀도 처리만 다름). 평가는 모두 같은 장치에서 했다.
- 다음 단계: Grid를 더 길게 학습해 공개 가중치와 비교, 북쪽 정렬 버전의 원인 확인, 3D 시점 평가
