## 0. 요약

- Bearing-UAV의 CSMG는 특징 지도를 하나의 벡터로 요약하는 과정에서 **위치 정보를 잃고**, **학습 도시에 과적합**된다.
- CSMG 자리에 **8×8 Grid Pooling**(칸별 평균 풀링)을 넣고 나머지 구조는 그대로 두었다. 모듈 파라미터는 CSMG의 약 **1/160**(1.31 M → 0.008 M)이다.
- 미학습 도시 3곳(NY, Paris, London) 160궤적의 1 km 닫힌 루프 항법에서:
  - 같은 조건으로 재학습한 CSMG보다 **시드 3개 모두에서 유의하게 높다** (평균 30.2% → 54.6%, 모두 p < 10⁻⁴).
  - 성능 향상의 원인은 **칸 수(위치 정보)와 파라미터 수(과적합 감소) 둘 다**이며, 칸 수의 효과가 더 크다.
  - 원래 Bearing(공개 가중치, 100 epoch)보다 낮 조건(p = 10⁻⁶)과 아주 어두운 조건(p = 0.018)에서 유의하게 높고, 중간 어두운 조건에서는 같다.
  - CSMG는 재학습하거나 저조도 영상을 섞어 학습해도 개선되지 않았다. **개선은 재학습이 아니라 모듈 교체에서 나온다.**
  - 학습을 20 epoch으로 늘리면 오히려 크게 나빠진다(53.1% → 20.6%).
- **최종 제안: CSMG → Grid Pooling 8×8, 4 epoch, 저조도 영상 50% 혼합 학습(`grid8_phys`).**

## 1. 문제 진단: CSMG는 무엇을 잃는가

Bearing-UAV는 UAV 영상과 위성 타일을 각각 VGG16 특징 지도(512×32×32)로 만든 뒤, CSMG로 1024차원 벡터 하나로 요약하고 비교한다.

**타일 맞히기 실험** (학습 없음, 블록 2×2 타일 중 UAV 영상 중심이 있는 타일을 맞힌 비율, 우연 수준 25%, 도시당 200샘플)

| 방법 | Tokyo (학습 도시) | NY (미학습 도시) |
| --- | --- | --- |
| CSMG (학습됨) | 85.5% | 59.0% |
| VGG 평균 풀링 (학습 없음) | 56.0% | 52.0% |
| dense 매칭 (요약하지 않음) | 95.5% | 96.0% |

- 같은 VGG 특징을 요약하지 않고 쓰면 미학습 도시에서도 96%를 유지한다. **위치 정보는 VGG 특징에 남아 있고, 요약 단계에서 사라진다.**
- CSMG는 학습 도시에서는 85.5%지만 미학습 도시에서는 학습 없는 풀링(52%)과 비슷하다. **CSMG가 학습으로 얻은 이득은 학습 도시에만 남는다.**

따라서 대체 모듈은 (1) 공간 배치를 보존하고 (2) 학습 도시를 외우기 어려워야 한다.

## 2. 제안 모듈: Grid Pooling

1. 1×1 conv로 512채널을 c채널로 줄인다 (BatchNorm, ReLU).
2. 특징 지도를 g×g 칸으로 나눠 칸마다 평균을 낸다.
3. 칸마다 L2 정규화 → 펼침 → 전체 L2 정규화. 출력 크기 c·g² = 1024로 CSMG와 같다.

- 출력 크기가 같아서 뒷단(RCE, CA, PSG, 회귀 헤드)을 수정 없이 쓴다.
- 칸별로 따로 요약하므로 "어느 칸에 무엇이 있는지"가 남는다.
- 8×8 기준 모듈 파라미터 0.008 M(CSMG 1.31 M), 전체 모델 17.13 M → 15.82 M. 연산량의 93%는 VGG이므로 전체 연산은 약 7% 줄어든다. 지도 저장량은 타일당 4 KB로 같다.
- Mac M3 GPU에서 모듈 연산은 CSMG보다 25~40배 빠르다(CSMG의 Non-local 연산 제거).

## 3. 실험 설정

### 3.1 학습 (모든 모델 공통)

| 항목 | 설정 |
| --- | --- |
| 데이터 | Bearing_UAV_90K (학습 도시 4곳: Tokyo, Taipei, Singapore, SF) |
| Train / Val | 95% / 5% (split seed 42) |
| 초기화 | VGG16만 공개 가중치로 얼림, 나머지(교체 모듈, RCE, CA, PSG, 헤드)는 새로 초기화 |
| Optimizer | AdamW, lr 3e-4, weight decay 1e-4, cosine schedule |
| Batch / Epoch | 64 / 4 (실험 B만 20) |
| Loss | SmoothL1, 위치 0.8 + 방향 0.2 |
| 증강 | 없음 (`_phys`만 저조도 혼합) |

- 대조군은 **원래 CSMG를 같은 설정으로 재학습한 모델(`csmg`)**이다. 공개 가중치는 원 논문 설정(100 epoch, 색상·노이즈·블러·cutout 증강)으로 학습되어 조건이 다르므로 보조 비교로만 쓴다.
- 원 Bearing-UAV 코드는 Train/Val/Test = 85/5/10으로 같은 분포 내부에서 나누지만, 본 실험은 내부 test 대신 **미학습 도시 항법**으로 최종 평가한다. 목적이 모듈 교체에 따른 도시 간 일반화 비교이기 때문이다.

### 3.2 평가

- 주희윤님의 닫힌 루프 항법 시뮬레이터, 1 km 궤적, 궤적 시드 2026
- 미학습 도시: NY 96 + Paris 32 + London 32 = **160궤적**
- 같은 궤적끼리 짝지은 **exact McNemar 검정**. 표의 `+a/−b`는 "앞 모델만 성공 a개, 뒤 모델만 성공 b개"다. 세 도시 합산.
- **같은 컴퓨터에서 평가한 숫자끼리만 비교한다.** 닫힌 루프 항법은 장치 간 미세한 수치 차이로 결과가 조금 달라진다(공개 가중치: 이준 Mac 32.5%, 김재홍 PC 36.25%). 같은 모델은 장치가 달라도 대부분 같게 나왔다(Grid8 seed 0: 두 장치 모두 85/160).
- 이하 4·6·7장은 이준 Mac, 5·8장은 김재홍 PC 결과다.

## 6. 원인 분리: 칸 수 대 파라미터 수 (이준)

실험 C에서는 출력 크기를 1024로 맞추느라 칸이 늘면 파라미터가 줄었다. 두 요인을 분리하려고 1×1 conv를 두 층(512→h→c)으로 만들어 파라미터 수만 따로 조절했다.

| | 파라미터 많음 (~0.53 M) | 파라미터 적음 (~0.01 M) |
| --- | --- | --- |
| **1×1 칸** | grid1 **26.3%** | grid1_h8 (0.015 M) **36.9%** |
| **8×8 칸** | grid8_h1024 (0.544 M) **43.8%** | grid8 **53.1%** |

| 비교 | 바꾼 요인 | 결과 | p |
| --- | --- | --- | --- |
| grid8_h1024 대 grid1 | 칸 수 (파라미터 많음) | +45/−17 | 0.0005 |
| grid8 대 grid1_h8 | 칸 수 (파라미터 적음) | +42/−16 | 0.0009 |
| grid1_h8 대 grid1 | 파라미터 수 (1×1) | +32/−15 | 0.019 |
| grid8 대 grid8_h1024 | 파라미터 수 (8×8) | +26/−11 | 0.020 |

- **두 요인 모두 독립적으로 유의하다.** 칸 수 효과(+16~18%p)가 파라미터 수 효과(+9~11%p)보다 크고, 두 효과는 거의 더해진다.
- 1장의 진단(위치 정보 손실, 학습 도시 과적합)과 정확히 대응한다. Grid Pooling 8×8은 두 문제를 동시에 줄인다.

## 7. 저조도 조건 (실험 D, 이준)

UAV 영상만 주희윤님의 물리 카메라 모델로 어둡게 만들어 평가했다. `iso_64`는 빛 1/64를 ISO 증폭(노이즈), `auto_256`은 빛 1/256을 자동 노출(블러+노이즈)로 처리한 조건이다. `_phys`는 학습 영상의 50%를 같은 카메라 모델로 무작위 어둡게(빛 1/400~1/8) 만들어 학습한 모델이다.

| 모델 | 낮 | iso_64 | auto_256 |
| --- | --- | --- | --- |
| 공개 가중치 | 32.5% | 56.9% | 45.6% |
| csmg | 23.1% | 43.1% | 32.5% |
| csmg_phys | 28.1% | 41.3% | 38.8% |
| grid (4×4) | 41.3% | 53.8% | 48.8% |
| grid_phys (4×4) | 43.1% | 56.9% | 48.1% |
| grid8 | 53.1% | 54.4% | 53.8% |
| **grid8_phys** | **57.5%** | **56.9%** | **57.5%** |

| 비교 | 낮 | iso_64 | auto_256 |
| --- | --- | --- | --- |
| grid 대 csmg | +46/−17, p=0.0003 | +38/−21, p=0.036 | +53/−27, p=0.005 |
| grid_phys 대 csmg_phys | +38/−14, p=0.001 | +42/−17, p=0.0015 | +34/−19, p=0.053 |
| csmg_phys 대 csmg | +25/−17, p=0.28 | +30/−33, p=0.80 | +36/−26, p=0.25 |
| **grid8_phys 대 공개 가중치** | **+54/−14, p=10⁻⁶** | +23/−23, p=1.0 | **+39/−20, p=0.018** |

- 저조도에서도 Grid가 같은 설정의 CSMG보다 유의하게 높다.
- **CSMG는 저조도 영상을 섞어 학습해도 개선되지 않는다**(세 조건 모두 p > 0.2). 데이터를 늘린 재학습으로는 CSMG의 한계가 풀리지 않는다.
- grid8_phys는 공개 가중치보다 낮과 auto_256에서 유의하게 높고 iso_64에서는 같다. 공개 가중치는 노이즈·블러 증강으로 100 epoch 학습된 모델이다.
- 참고: 모든 모델이 낮보다 iso_64에서 성공률이 높았다. 카메라 처리만 적용하고 노이즈를 뺀 조건(`clean_1`)은 낮과 같아서, ISP 처리 때문은 아니다. 원인은 확인하지 못했으므로 저조도 결과는 모델 간 상대 비교로만 사용한다.

## 8. 장기 학습 (실험 B, 김재홍)

| 모델 | NY | Paris | London | 전체 |
| --- | --- | --- | --- | --- |
| 공개 가중치 | 36/96 | 13/32 | 9/32 | 36.25% |
| **Grid8 4 epoch** | 45/96 | 19/32 | 21/32 | **53.13%** |
| Grid8 20 epoch | 19/96 | 7/32 | 7/32 | 20.63% |

- 20 epoch 대 4 epoch: +9/−61, p = 1.3×10⁻¹⁰. 20 epoch 대 공개 가중치: +17/−42, p = 0.0016.
- 학습 도시 검증 오차는 계속 줄었다(epoch 4 20.6 m → epoch 20 15.4 m).
- 검증 데이터가 학습 도시와 같은 분포이기 때문에, 검증 오차로는 보이지 않는 **학습 도시 과적합**이다. 4·6장에서 본 "학습 도시 오차가 낮을수록 미학습 도시에서 나쁘다"는 패턴과 같은 방향이다.
- 4 epoch은 결과를 보기 전에 정한 기본값이므로 본 결과에 test 튜닝은 없다. 앞으로 epoch 수를 더 탐색하려면 미학습 도시 중 별도 검증 도시를 두어야 한다.

## 9. 결론

1. **CSMG의 문제**는 위치 정보 손실과 학습 도시 과적합이다(1장).
2. **Grid Pooling 8×8**은 두 문제를 동시에 줄이며(6장), 같은 조건의 CSMG 대비 미학습 도시 항법 성공률을 시드 3개 모두에서 유의하게 높인다(평균 +24%p, 5장).
3. **재학습은 해결책이 아니다.** CSMG는 같은 조건 재학습, 저조도 혼합 학습(7장)으로 개선되지 않았고, Grid도 오래 학습하면 나빠진다(8장). 개선은 구조 교체에서 나온다.
4. 저조도 혼합 학습을 더한 **grid8_phys**는 원래 Bearing보다 낮(57.5% 대 32.5%)과 아주 어두운 조건(57.5% 대 45.6%)에서 유의하게 높고, 모듈은 1/160 크기다. 단, 전체 모델의 연산은 대부분(93%) VGG16에서 나오므로 전체 파라미터는 약 8%, 연산량은 약 7%만 줄어든다. 드론 탑재를 위한 실질적인 경량화는 백본 교체가 필요하다.

**최종 제안 설정:** Grid Pooling 8×8 + 4 epoch + 저조도 50% 혼합 학습

## 10. 한계

- 2D 위성 크롭 시뮬레이션이며 나침반 heading을 안다고 가정했다. 3D 시점과 실제 비행은 확인하지 않았다.
- 칸 수·저조도 실험(4·6·7장)은 시드 하나다. 시드 반복은 Grid8과 CSMG에 대해서만 했다(5장).
- 미학습 도시 3곳을 평가와 모델 선택(격자 크기)에 함께 썼다. 엄밀하게는 검증 도시와 test 도시를 분리해야 한다.
- 장치 간 결과 차이가 있어 4·6·7장과 5·8장의 숫자는 직접 섞지 않는다.
- 기존 연구에도 격자 기반 풀링(Spatial Pyramid Pooling, R-MAC 등)이 있다. 본 작업의 기여는 새 풀링 방법이 아니라 **Bearing-UAV의 실패 원인 진단과, 그에 맞는 교체 및 검증**이다.
